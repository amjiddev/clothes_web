                        SECURITY IMPLEMENTED
================================================================================

✅ Authentication
   - All routes require 'auth' middleware
   - User must have verified email ('verified' middleware)
   - Role-based access (admin.only / receptionist.only)

✅ CSRF Protection
   - All POST requests require X-CSRF-TOKEN header
   - Token validated by Laravel middleware
   - Token obtained from meta tag in layout

✅ User Isolation
   - Orders belong to specific user via user_id
   - Measurements belong to specific user via user_id
   - Contact messages visible to admin only
   - No cross-user data leakage possible

✅ XSS Prevention
   - All user input escaped using escapeHtml() function
   - HTML special characters converted to entities
   - No direct innerHTML from user-provided data
   - Safe DOM manipulation

✅ Input Validation
   - Type validation: in:order,contact_message,measurement
   - ID validation: integer type
   - All request parameters validated before processing

================================================================================
                        TROUBLESHOOTING
================================================================================

Issue: Bell icon not showing
  Solution: Check if component included in navbar
           Clear view cache: php artisan view:clear

Issue: Badge shows 0 always
  Solution: Run migrations: php artisan migrate
           Verify database has is_seen column

Issue: Notifications don't disappear after clicking
  Solution: Check browser console for JS errors
           Verify database is_seen column updated

Issue: 404 errors on API calls
  Solution: Run route:clear: php artisan route:clear
           Restart application

Issue: CSRF token errors
  Solution: Verify meta tag in layout: <meta name="csrf-token">
           Check POST requests include header: X-CSRF-TOKEN

Issue: Modal won't open
  Solution: Verify Bootstrap 5.3.0 loaded
           Check browser console for JS errors

Issue: Permissions denied error
  Solution: Verify user role is admin or receptionist
           Check database: SELECT * FROM model_has_roles

Issue: Database columns missing
  Solution: Run migrations: php artisan migrate
           Verify columns exist: DESCRIBE orders;
